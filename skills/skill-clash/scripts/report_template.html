SKILL-CLASH

読む skill を2つに絞り、LOADOUT.md にして Claude に渡す

Claude に skill を一度に何個も読ませると、指示がぶつかって平均的な出力になる。

この画面に依頼を1行入れると、読む skill を「作る用1つ＋点検用1つ」に絞る。ぶつかる所を決めたら、結果を LOADOUT.md にして Claude に先に読ませる。

例: 「カフェの LP を作る」と入れると、 で作り、 で点検する、と出る。

②何を作るかを1行で書く

日本語でも英語でもよい。個の skill の説明（description）と語が重なるものを探す。

例を入れる:

全部見る

提案に納得できないときに開く。一覧から候補に足すと、③に戻って選び直せる。

skill を全部見る
skill種類語数説明操作
軸ごとの立場の対照表を見る

✓ 勧める　✗ 避ける　~ 両方を言う。印にマウスを乗せるか、Tab で移ると根拠の文が出る。

説明が似ている skill の対を見る

説明の語の重なり（Jaccard 0.25 以上）。同じ依頼で両方が呼ばれやすい。

skillskill重なり共通の語

IFScale: 同時に守らせる指示が増えるほど、最上位のモデルでも守られる割合が下がる。arXiv:2507.11538

ConInstruct: モデルは指示のぶつかりに気づいても、ほとんど口に出さず、黙って片方に従う。arXiv:2511.14342

候補は説明の語の重なりで、立場は SKILL.md の文の手がかりで推定している。根拠の行を原文で確かめてから決める。
